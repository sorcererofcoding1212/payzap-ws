# Payzap WebSocket Service

This repository contains the WebSocket service for the Payzap platform.

The service is responsible for delivering real-time notifications and
updates related to wallet activity, transactions, and payment requests.
It maintains active connections with clients and broadcasts events
triggered by the main Payzap application.

For complete project documentation, system architecture, and links to all
related services, refer to the root Payzap repository:

👉 https://github.com/sorcererofcoding1212/payzap
